# Replay samples (M1-10 → for M5's `replay.py`)

Time-ordered slices of the **held-out test split**: flows the models never train or tune on. Generated by
`python -m ml.data.make_replay` (deterministic, seed 11); small enough (5 MB) to live in git so M5 does not need the 10 GB raw data.
`manifest.json` has the exact counts, time spans and ground-truth mix per file.

## Columns

`flow_id, observed_at (UTC ISO), t_rel_s, src_ip, src_port, dst_ip, dst_port, protocol, ground_truth, tool, <features…>`

* `t_rel_s` = seconds since the file's first flow, for pacing (`--speed 1` = original timing).
* `ground_truth` = family (`BENIGN`, `DDoS`, `Botnet`, … / `Malicious`, `Outlier`); `tool` = raw dataset label (`DDoS-HOIC`).
  **Never send these to the model**; `ground_truth` goes in `FlowRecord.ground_truth` (replay-only scoring), `tool` is for your console output.
* The feature columns are exactly the names in the schema's spec (`nscore/contracts/feature_spec.json` or `feature_spec.luflow.json`) =
  the keys of `FlowRecord.features`. **`protocol` appears once** and is both `FlowMeta.protocol` and `features["protocol"]`.
* No missing values (non-finite ones were replaced by the spec's train median, counted in the manifest).
* Ports are display-only; LUFlow's "no port" (-1) is written as 0 so the row validates as `FlowMeta`.
* Build a record like this (checked against the contracts by tests/test_replay_samples.py, all 12 files):
  ```python
  feats = {c: float(r[c]) for c in feature_cols} | {"protocol": float(r["protocol"])}
  FlowRecord(meta=FlowMeta(flow_id=r["flow_id"], observed_at=r["observed_at"], src_ip=r["src_ip"], dst_ip=r["dst_ip"],
             src_port=int(r["src_port"]), dst_port=int(r["dst_port"]), protocol=int(r["protocol"])),
             features=feats, ground_truth=r["ground_truth"])
  ```
  Read `src_ip` / `dst_ip` as strings (`pd.read_csv(..., dtype={"src_ip": str, "dst_ip": str})`).

## Files

**CIC schema → load the 2018 bundle** (`netsentinel-bundle`, or `…-holdout-botnet` for the "never seen a botnet" act)

| File | Flows | Mix (benign / malicious / outlier) | Use |

| `luflow_2020-06` | 10,000 | 6,872 / 1,872 / 1,256 | Same-period baseline: drift should stay `ok` |

LUFlow files are **random samples** of the month's test block (re-sorted by time), not contiguous bursts, so their `t_rel_s` spans days: pace by
flows per second, not by `t_rel_s`. 10,000 flows are enough for PSI over a 2,000-flow window, but check `/v1/drift` against the files before the dry run.

## Caveats

* The 2018 attack files are slices of the **test** blocks. If M2 changes the split, regenerate these (`python -m ml.data.make_replay`).
* `2018_infiltration_nmap` has only Wednesday's test flows (3,581); Thursday's go to the other test block.
* Real LUFlow flows carry no attack type; the model can only say `Malicious` or a novel anomaly.
